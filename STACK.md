| `NODE_ENV` | Runtime environment (`production`, `development`, `test`) | Yes |
| `PORT` | API server listen port (default: `3090`) | No |
| `DATABASE_URL` | PostgreSQL connection string | Yes |

| `OTEL_ENABLED` | Enable OpenTelemetry tracing exporter | Optional |
